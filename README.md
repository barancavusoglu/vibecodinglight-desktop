# VibeCodingLight Desktop

Desktop companion for the [VibeCodingLight](https://www.vibecodinglight.com) desk robot, showing the status of your local AI coding sessions.

Windows beta and macOS source preview. The source is public for inspection. Session tracking runs locally; the Windows app can contact the official website to check for updates.
