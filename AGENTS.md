# Repository instructions

- Use English for commits and public documentation. Keep public documentation minimal.
- Keep this repository limited to desktop sources. Preserve third-party license notices.
- Preserve user-owned settings and hooks. Do not change installed apps, assistant configuration or devices while testing.
- Check Windows/macOS and Codex, Claude Code and OpenCode applicability when changing shared behavior. Run checks appropriate to the change.
- Never commit credentials, personal data or private keys. Publish releases only when authorized.
